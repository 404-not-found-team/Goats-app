# Márka-képek (rajzolt üvegek)

- Egy márkához **egy** kép: `<marka>.webp`, ahol a `<marka>` a `sql/03_ital_marka.sql`-ben
  szereplő slug (kisbetűs, ékezetmentes, kötőjeles), pl. `finlandia.webp`, `jack-daniels.webp`.
- Méret: négyzetes, legfeljebb 512×512 px.
- Formátum: WebP, átlátszó háttér ajánlott.
- Ha egy márkához nincs fájl, az app automatikusan a kategória-ikont mutatja (nem törik el).
- Márkanév nem szerepelhet a képen (jogi okból).
